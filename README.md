## 本地查看

全部样式与少量交互脚本都在 `index.html` 中，无需安装前端依赖或进行构建。

可以直接用浏览器打开 `index.html`，也可以在本目录运行：

```sh
python -m http.server 8765
```

然后访问 `http://localhost:8765`。

## 页面实现

- HTML、CSS 与原生 JavaScript；无外部字体、图片或第三方脚本请求。
- 手机单列、电脑双列作业布局；内联 SVG 展示研究流程概念，不是实验数据。
- 原生 `details` 展开计划；状态筛选不影响无 JavaScript 时的内容阅读。
